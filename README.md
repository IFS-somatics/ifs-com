- Unattached Burdens and Guides

Free 30-minute online consultation, no obligation. Sessions are offered in English and Swedish, online worldwide and in Berlin.

## Hosting

The site is a static HTML site hosted on [GitHub Pages](https://pages.github.com/):

1. **Settings → Pages**
2. Source: *Deploy from a branch*, branch `main`, folder `/ (root)`
3. Custom domain: `YOURDOMAIN.com`, with *Enforce HTTPS* ticked

To update the site, edit a file and commit the change. The live site updates within a couple of minutes.
